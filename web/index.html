G

Google Calendar

Migration

Bring your existing Google Calendar setup into Calden without creating duplicate calendars or duplicate events. Google Takeout can carry older copies of the same event UID in more than one source file after an event has moved; Calden treats those as one logical event, previews calendar matches, and lets you approve where every calendar goes.

1
Export from Google Calendar

In Google Calendar, open Settings, choose Import & export, then choose Export. Google downloads one ZIP containing your calendars.

2
Review before importing

Drop the export below and Calden will compare calendars, detect repeated Google event UIDs across the export, and keep only the newest copy. Nothing is created during this step.

3
Choose where each one belongs

Accept a suggested match, choose another existing Calden calendar, skip it, or explicitly create a new calendar. Then import.

Nothing is created until you review the mapping and start the import. The export stays on your Calden server. If an older Calden import already created duplicate database rows, use the repair tool below instead of deleting calendars or importing everything again.

Existing Calden data

Repair duplicate Google events

Scan the events already stored in Calden. This does not delete calendars and does not re-import your calendar. Your original Google export is used only to identify which existing Calden copy is the current one.

M

Monita

Send household-wide event reminders through Monita.

For scoped access, create a Monita service account with channel:read and message:write permissions. Legacy channel tokens still work.

Connection checks channel access and sends a test before saving. Only the encrypted credential is stored in Calden; the token never appears again in the browser.
