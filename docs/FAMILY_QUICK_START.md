# Calden: Quick Start

**Calden** is a shared family calendar. Everyone can see the schedules they have access to, and each person can use Calden from a phone or computer.

## First-time setup

1. Open the Calden website address provided by the person who installed it.
2. Follow the setup screens to create the family space and the first account.
3. Add other family members under **People**.
4. Create calendars under **Calendars**. Examples: **Family**, **Appointments**, **School**, and **Bills**.
5. Decide who can see or change each calendar. Not every calendar has to be shared with everyone.
6. Add an appointment using **Add event**. Before saving, check the complete day, month, year, and time.
7. Go to **Calendar** to see upcoming events. Use **Agenda** for a simple list.

## Everyday questions

**Where did my appointment go?** Go to Calendar and move to the month you selected. An alert's **Notified** date is when the message was sent, not the appointment date.

**Can I hide Bills or Agenda?** An administrator can turn these sections off in **Settings**. Existing data remains available if they are enabled again.

**Why didn't I hear a reminder?** Check the reminder settings, your phone's notification permission, volume, and Android notification channels. The upcoming Android sound controls will let each phone choose sounds or turn off alerts for a calendar.

**Who can change appointments?** People allowed to edit that calendar. Other people may only be allowed to view it.

**What's a recurring event?** An event that repeats, like soccer every Wednesday or a bill each month.

**What if a save warns me that it couldn't verify the date?** Check Calendar for the appointment *before* saving it a second time. This prevents accidental duplicates.

## Updating Calden

The server has a built-in **Updater**. A family administrator can check for a new version and install it without typing development commands. Back up your family calendar before major updates.

The Android app is a separate installation. An Android source-code update does **not** mean a new phone app is ready: an actual APK must be successfully built, verified, and distributed.

## A note on names

The product is called **Calden** (not “CalDen”). Technical folder names, older filenames, and API addresses sometimes use lowercase `calden` and should not be manually renamed.
