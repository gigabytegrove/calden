# Calden v1.4.9 — October 2026 Security Update

## Important security maintenance

This release refreshes the Calden server build to **Go 1.27.3**, including the October 19, 2026 crypto/x509 security fix (CVE-2026-111943). The web asset build uses **Node.js 22.23.4**, which includes the October 21, 2026 Node.js security fixes. Both changes address underlying application/runtime toolchains; they do not require you to recreate any calendar, user, chore, or meal-planning data.

## What changes

- Rebuild the Calden Go server with patched Go 1.27.3.
- Pin the web build runtime to patched Node.js 22.23.4.
- Rotate browser cache-busting version identifiers to 1.4.9 so updated JavaScript and CSS are loaded after installation.
- Update release-build and validation recipes to use the patched toolchains.
- Correct the release smoke test to use the actual `VERSION` file instead of a stale version string.

## Upgrade instructions

Use Calden's built-in updater when **v1.4.9** is published and its verified installable assets are available. Back up Calden's database and persistent volumes before updating. Container deployments should pull the published updated image and verify the app health endpoint; existing installations are not modified merely by publishing this release.

## Verification and scope

Publication must be gated on Go tests, browser/first-run checks, Docker health, generated static assets and checksum-verified AMD64/ARM64 runtime archives. This is a maintenance update, not a new feature release.
