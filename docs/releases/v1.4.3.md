# Calden 1.4.3 — Appointment date reliability

This server/web patch builds on Calden 1.4.2 without altering or deleting existing appointments.

- Calendar creation with a date-only hint preserves the exact selected day in every supported timezone.
- After saving, the web calendar navigates to the saved appointment date instead of remaining on the current month.
- Event creation, whole-event updates and recurring occurrence updates return the actual start/end instants stored in PostgreSQL. The editors compare those values with the selected instants and show a warning if they do not match.
- Appointments show a full year. The inbox separately labels the notice creation date as **Notified** to avoid confusing it with the scheduled appointment.
- API integration and browser regression tests include January 13, 2027 versus October 13, 2026, plus Eastern/Western timezones and DST boundaries.
- Compatible with Calden Android 1.4.1; Android 1.4.2 will add additional native date and sound settings when a verified APK can be built.

Upgrade via Calden's in-app updater. No configuration or migration is needed beyond the 1.4.2 schema. Back up before updating.
