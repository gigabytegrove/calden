# CalDen 1.2.11 — coordinated transparent branding

Restores the **user-approved CalDen logo and icon** throughout the supported Web and Android brand surfaces.

- Web: alpha SVG full logo on the sign-in screen; alpha SVG icon in sidebar and favicon.
- Android: original SVGs stored in app assets; converted to native alpha-preserving VectorDrawables for login, app header, and adaptive launcher foreground.
- Removes dependence on damaged legacy WebP and temporary checkmark branding in active web markup.
- No baked-in white image backgrounds; Android adaptive icon uses a separate system-required background layer.
- Coordinated version identifier **1.2.11** in both projects.

Android APK must be compiled and signed by the native Gradle build before deployment.
