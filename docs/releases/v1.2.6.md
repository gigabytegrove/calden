# CalDen v1.2.6

Coordinated CalDen server and browser release aligning API changes with the Android 1.2.6 development source.

## Added
- Per-user registered device management under Settings > My devices.
- Optional Request Confirmation when scheduling events.
- Per-assignee confirmation and Request Change responses with a reason.
- In-app notifications to the original scheduler after a response.
- Read/write confirmation endpoints for web and Android.
- Validation that confirmation replies belong to actual event occurrences, including recurring events.
- Additive PostgreSQL migrations for devices and confirmations.

## Important
- Native Android push delivery and Monita/ntfy provider setup are not yet implemented.
- The Android 1.2.6 source has not been device-verified.
- Update publication depends on the GitHub release workflow succeeding; deploying to a running Docker installation is separate.
