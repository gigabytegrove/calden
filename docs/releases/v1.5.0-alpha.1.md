# Calden 1.5.0-alpha.1 — Local test candidate

**Status:** versioned source alpha on `alpha/v1.5.0-alpha.1`, built locally with Docker Compose. **Not yet a published GitHub Release, container registry image, or production release.** The last stable release remains **1.4.8**.

## Scope included for this test

This alpha captures the additive family-platform work on the current development branch: personal dashboards and household appearance preferences; guardian-managed child accounts and restricted views; shopping lists with categories, permitted assignments, reorder thresholds and history; recurring routines, chores, rewards and allowances; school activities; home maintenance and pet schedules; optional RecipeCove meal-planning integration candidate; and independent due/advance family-care notifications.

Features still needing end-to-end validation and external integrations are explicitly **not claimed complete**. The native Kotlin Android project is not present in this repository, and RecipeCove write-token provisioning must be validated against its actual service.

## Isolated install from source

Prerequisites: Docker Engine with the Docker Compose v2 plugin, Git, and sufficient resources to build Go 1.24 and Node 22 stages (memory and disk headroom needed).

```bash
git clone --single-branch --branch alpha/v1.5.0-alpha.1 https://github.com/gigabytegrove/calden.git calden-alpha-test
cd calden-alpha-test
docker compose -f docker-compose.alpha.yml config --quiet
docker compose -f docker-compose.alpha.yml up -d --build
docker compose -f docker-compose.alpha.yml ps
```

Open `http://localhost:18787` on the Docker host, or `http://<host-LAN-IP>:18787` from a trusted LAN client. Firewall the port; **never expose this alpha to the public Internet**.

The alpha's project name is `calden-alpha` and it creates its own `calden-alpha_calden-db`, `calden-alpha_calden-data` and `calden-alpha_calden-secrets` volumes. The application listens on container port 8787 and uses host port 18787 (overridable with `CALDEN_ALPHA_PORT`). A new secret is generated on first startup. Stable Compose volumes are not mounted.

**Build acceptance:** The alpha Dockerfile runs Node web tests and Go tests; a failing test stops image construction. PostgreSQL migration 001–040 runs on the new empty alpha database during first boot. The runtime health endpoint is `/api/health`.

## Local test checklist

1. Confirm the UI shows version `1.5.0-alpha.1` and the /api/health endpoint returns `ok: true`.
2. Complete setup in the alpha database with a **test-only administrator account**; don't reuse a production backup for the initial smoke test.
3. Exercise personal dashboard appearance, widget choices, household toggles and navigation on desktop and mobile widths.
4. Create a child and guardian; verify restricted sign-in, approved modules, and blocked API access to admin-only views.
5. Create shared and private shopping lists, categories, assignees, threshold flags and history; check that a non-owner cannot see private lists.
6. Test chores and routines across recurring dates, reward claiming, guardian approval and allowance history.
7. Create school/home/pet schedules using each recurrence and reminder lead choice. Check that completing/skipping an occurrence dismisses outstanding alerts and that school notices reveal no student identity.
8. Exercise RecipeCove only if a compatible dedicated test provider and appropriately scoped API token are available; otherwise record it as integration-blocked.
9. Check browser console, narrow-screen layout, navigation deep links, health, and server logs. Restore/export and Android-native equivalence remain separate release blockers.

## Logs, health and stopping

```bash
docker compose -f docker-compose.alpha.yml ps
docker compose -f docker-compose.alpha.yml logs --tail=250 calden db
docker compose -f docker-compose.alpha.yml down
```

`down` stops/removes containers and network without deleting named volumes. **Do not add `--volumes`** unless you explicitly intend to erase alpha data. Leave the stable Compose project running independently.


## Publish the GitHub prerelease and tag for the built-in updater

Calden uses **a normal GitHub Release/tag**, with binary \`calden-linux-amd64.tar.gz\` and \`calden-linux-arm64.tar.gz\` runtime assets plus \`SHA256SUMS\`. The tarballs are *attachments to the release*, not an alternative release type. A source branch alone is invisible to the updater.

The \`scripts/publish-alpha.sh\` script works on a Linux Docker host with Docker Engine, Git, Bash, \`sha256sum\` and the GitHub CLI (\`gh\`). Sign in with a GitHub PAT using \`gh auth login\`, or supply \`GH_TOKEN\` as a private environment variable. Run it from a clean checkout of \`alpha/v1.5.0-alpha.1\`:

\`\`\`bash
bash scripts/publish-alpha.sh
\`\`\`

It verifies the remote branch SHA, builds and tests Tailwind/Node and Go 1.24 in Docker, cross-compiles amd64/arm64 Linux runtimes, assembles the updater's complete binary+web tarballs, checks SHA256 hashes, and publishes the assets and tag using \`gh release create --prerelease\`. It then downloads and verifies the published files. **No GitHub Actions workflow is required.** A failure before publication does not create the tag/release. If uploading fails after release creation, GitHub might hold a partial draft; inspect it rather than blindly overwriting.

Only *after* publication and verification should the Calden updater be set to **Alpha** and checked for \`v1.5.0-alpha.1\`. Back up the existing PostgreSQL database and data volume before any in-place updater installation. For an initial smoke test, the isolated \`docker-compose.alpha.yml\` remains safer because the family expansion introduces unaccepted schema migrations 034–040.

## Known limitations / acceptance gates

- The connected GitHub source review has **not executed** a genuine complete Go 1.24 build, PostgreSQL migration, full Node test suite or Docker image build. The alpha's local build must pass those before you can treat it as runnable.
- Dedicated `CALDEN_TEST_DATABASE_URL` integration tests require a separate throwaway PostgreSQL database named `calden_test` or prefixed `calden_test_`; they are skipped by default and not included as a pass claim.
- Native Android source is not in this checkout. Android acceptance remains outstanding.
- The recipe provider authorization boundary, calendar subscription sync, full household backup restore, and optional device adapters remain unfinished or unverified.
- Do not aim Calden's built-in update installer at this source alpha; no binary release assets have been published. Future source commits should not be mistaken for an immutable tag.

**Promotion rule:** Only publish a prerelease tag and Linux assets after the isolated build, migrations, role/security tests and smoke tests pass. Do not upgrade the existing stable installation using this alpha.
