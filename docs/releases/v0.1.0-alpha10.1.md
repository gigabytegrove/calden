# CalDen 0.1.0-alpha10.1

> **Superseded duplicate-repair note:** Alpha10.1 contains the Alpha10 import behavior, but Alpha11 is the authoritative fix for duplicate Google-imported event rows already stored in CalDen. Use Alpha11's in-place repair workflow instead of deleting calendars or doing a destructive fresh import.


This is the corrected Alpha10 release after fixing CalDen's in-app updater version ordering.

## Updater fix

Older Alpha9 builds compared prerelease labels lexically, so `alpha9` was incorrectly considered newer than `alpha10`. That made Alpha10 disappear from the Updates page even though the GitHub release existed.

CalDen now compares numeric prerelease suffixes naturally:

- alpha10 is newer than alpha9
- alpha11 is newer than alpha10
- beta10 is newer than beta2

Existing Alpha9 installations should first install the one-time **0.1.0-alpha9.1** bridge. After it restarts, check for updates again and **0.1.0-alpha10.1** will appear normally.

## Includes Alpha10

Alpha10.1 contains the complete Alpha10 feature set:

- per-occurrence Bill Pay paid/unpaid status
- assigned payer vs. actual payer
- actual amount paid and paid date
- paid/outstanding monthly totals
- paid-by-person breakdowns
- Google Calendar moved-event duplicate detection
- revision-aware duplicate suppression
- repair of duplicate events created by older imports
- preservation of CalDen-side data during safe duplicate reconciliation

No additional database migration beyond Alpha10 is introduced by this updater correction.
