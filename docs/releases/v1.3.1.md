# Calden 1.3.1 — Android usability and calendar refinements

Coordinated Calden 1.3.1 release.

## Android refinements
- Redesigned event detail dialog with clear date/time formatting, calendar, location, and note icons, bill status, and assigned household member portraits.
- Replaced bill list avatars with financial status icons (allocated, partial, paid/cleared, no balance).
- Reworked 30-day calendar: dynamically sized month grid fills available height; day agenda opens on date selection in a scrollable bottom sheet rather than occupying a permanent bottom pane.
- Retains 1.3.0 direct Calden WebSocket notifications, native confirmation actions, event reminders and REST inbox recovery.

## Compatibility
- Server and web version 1.3.1 coordinates with Android versionName 1.3.1, versionCode 23.
- Android changes require a freshly compiled and signed APK; publishing a server runtime does not build Android.
- Build, smoke and actual device tests must be checked before treating the update as production verified.
