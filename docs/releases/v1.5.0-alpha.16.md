# Calden v1.5.0-alpha.16 — Consistent household UI and visible tracking history

## Complete UI integration pass
- The existing Calden design is standardized across calendar, agenda, bills/payment workflows, notifications, family dashboards, shopping and supplies, children/guardian management, rewards, routines, RecipeCove integration, Packages, and the Settings workspace.
- Light mode, dark mode, and household palette presets share controls, surface and typography rules instead of duplicated legacy styling. Calendar identity colors and member avatars remain unchanged.
- Shared form heights, spacing, button/action alignment, accessible focus, responsive grids and safe overflow are applied to desktop/tablet/mobile screens, including 360px layouts and modal dialogs.
- No destructive migrations or new data model are required.

## Package Tracking history
- Every shipment has an explicit **Tracking history** button, independently of editing, with a full read-only timeline and its own dialog.
- Shows event time, recorded status, detail and separate **Carrier scan**, **Shipping email**, or **Entered in Calden** provenance labels.
- Supports refresh and older pages beyond 100 events. Error/loading/empty states are informative, and shared viewers have history access without deletion rights.
- Package list shows the latest carrier activity or explicitly notes that no verified carrier scan exists. Carrier checks and self-repair continue without false successful tracking events.
- PostgreSQL integration tests cover private, shared and child access, page ordering and pagination; DOM tests exercise shared-viewer history, paging and UI appearance.

## Release verification gates
The published release must pass Go + PostgreSQL regressions, web/DOM regressions, Chromium CSS compliance at 360px/768px/1280px in light and dark mode, separate native portable runtime tests, exact-commit Docker build, multi-architecture image publication and SHA256SUMS for both application and tracker archives. Do not equate green CI with a verified user installation.

## Outstanding separate operational acceptance
Actual carrier scans with real tracking numbers, user-host automatic repair, real Android push/permissions and complete RecipeCove/Google OAuth integrations are not proven by this UI release. They remain open in the Calden engineering register, not silently accepted.
