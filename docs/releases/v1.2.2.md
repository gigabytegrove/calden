# CalDen 1.2.2

Corrected, tested version of the Settings and updater improvements originally targeted for 1.2.1.

- Dark monochrome hourglass on high-contrast warning-gold allocation badge.
- Integrations, Updates, Backups are available under Settings with dedicated shareable URLs and backwards-compatible aliases.
- Successful update shows a concise result and collapses previous progress/activity; live installation and failure details remain visible.
- Repair the Settings pane `querySelectorAll` startup regression caught by authenticated browser tests before publishing.
- No database migrations or other functional changes.
