# CalDen 1.2.0

## Calendar and Bill Pay
- Use an hourglass on Bootstrap-warning gold for allocated bills.
- Display one green check for paid and cleared bills. The detailed payment states remain accessible in the bill details dialog.
- Remove redundant All Day and payment-state text from calendar bill tiles. Display the actual payer's avatar or initials for paid bills. Keep ordinary event assignee avatars.
- Fit the 1-day and 7-day timeline to desktop viewport height where practical, while preserving scrolling for dense data and smaller screens.

## Agenda
- Start with upcoming events rather than old calendar history.
- Add timeframe (7, 14, 30, or 90 days), event/bill and calendar filters alongside search.

## Alerts
- Dismiss individual notification inbox items, independently for each user, without erasing their underlying events or bill records.
- Persist dismissals so bill review reminders are not immediately recreated on refresh. A substantive change in the review message can reopen a previously dismissed alert.

## Personal reminders and Android
- Allow a personal reminder to target a named household member. When no recipient is specified, the reminder targets the event assignees (or everyone when unassigned).
- Include recipient IDs in event APIs, create/update/occurrence editing and Android models.
- The companion Android 1.2 source adds recipient-filtered local notification alarms, periodic background calendar sync and tap-through event details.
- Phone notifications require the Android app installed and signed in as the intended household member. The operating system can delay background synchronization and alarms; this is not an always-on server-initiated FCM push.

## Upgrade
CalDen automatically applies migration 015 to track dismissed notifications and recipient assignments. A safety backup is performed by the in-app updater. No duplicate-event repair changes are included.
