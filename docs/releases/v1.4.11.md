# Calden 1.4.11 — Automatic Package Email Discovery

Extends the optional Package Tracking introduced in v1.4.10. It remains disabled by default; existing calendar data and shipment records are preserved.

## Added

- Built-in Gmail IMAP discovery using a dedicated app password and verified TLS on port 993. Other IMAP servers must be allowlisted by the server operator.
- Per-user encrypted mailbox settings. Credentials are never returned to the browser; disconnecting removes the credential.
- A bounded background worker checks opted-in mailboxes about every 15 minutes using read-only IMAP commands. UIDVALIDITY-aware cursors prevent duplicate fetches, and messages are never marked read.
- Connection, scan-request, status and disconnect controls in Packages → Import email.
- Tentative delivery-date extraction from unambiguous shipping-email estimates. New email-imported packages appear on their expected calendar day without overwriting any previously maintained shipment.
- Shared deduplicating importer for manual email imports, inbound mail-gateway forwarding, and IMAP scanning.
- Automated Go and JavaScript checks, including IMAP protocol, host restrictions, date parsing and existing package tests.

## Security and compatibility

- Package Tracking and per-user mailbox scans require separate opt-ins. Gmail app passwords are supported only when Google account settings permit them.
- Outlook.com and Microsoft 365 require OAuth2 and are not supported by this password-based IMAP connection. No carrier passwords or browser automation are used.
- Messages are read without modifying the inbox; raw email content is not retained. The initial scan examines up to 40 recent messages within 14 days, and each message is capped at 256 KiB.
- Migration 043_package_mailboxes.sql adds encrypted mailbox settings and IMAP cursor state. Migrations 041–042 from v1.4.10 remain unchanged.
- Carrier APIs, OAuth connections and native Android package UI are not implemented in this release.

See the Package Tracking documentation for setup details.
