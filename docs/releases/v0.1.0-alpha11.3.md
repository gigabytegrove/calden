# CalDen 0.1.0-alpha11.3

This release fixes all-day calendar rendering and expands Bill Pay into a real bill lifecycle.

## Fixed

- Fixed Google/all-day events appearing on both the intended date and the previous date in local time zones.
- All-day dates are now treated as calendar dates instead of UTC instants across the calendar grid, agenda, notifications, bill views, and event editor.
- Google duplicate reconciliation now preserves bill allocation records.
- Bill activity changes refresh actionable notifications immediately.

## Bill Pay

- Added **Allocated** status for money moved into a bill-pay account before autopay occurs.
- Added allocated amount, allocation date, and the person who allocated the funds.
- Bill lifecycle now supports **Due → Allocated → Partial/Paid → Cleared**, plus **No balance**.
- Added one-click **Mark cleared** for recorded payments.
- No-balance months clear both payment entries and allocated-fund records for that occurrence.
- Bill Activity now shows due, allocated, paid, remaining, and current status together.
- Added end-of-day bill follow-up notices for open all-day bills, with timed bills using their programmed due time.
- Bill follow-up notices open the Bill Activity panel directly and update as the bill state changes.

## Validation

- Added regression coverage for UTC-midnight Google-style all-day events so they render on exactly one calendar date.
- Added allocation, split-payment, paid, cleared, and no-balance lifecycle coverage.
- Existing Go build, vet, test, Docker startup, browser UI, calendar import, recurrence, and Google migration checks remain in CI.
