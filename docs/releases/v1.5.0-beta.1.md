# Calden v1.5.0-beta.1 — Security maintenance

This security maintenance build updates the approved Calden **1.5.0 Beta** feature line without reverting to 1.4.x. It preserves package tracking and its credential-free parcel engine, shared calendars, family tools, meals, web UI, updater, and the persistent PostgreSQL database.

## Security baseline
- Go toolchain and standard library: **1.27.4** (previous 1.24).
- PostgreSQL driver `github.com/jackc/pgx/v5`: **5.13.0** (previous 5.7.6), including fixes associated with CVE-2026-33815, CVE-2026-33816, and CVE-2026-41889.
- Supporting `golang.org/x/crypto` **0.58.0**, `golang.org/x/sync` **0.24.0**, `golang.org/x/text` **0.43.0**; `github.com/jackc/puddle/v2` **2.2.3**.
- Docker Go compilation stage now explicitly uses Go 1.27.4; build refuses an outdated compiler.

## Feature and updater preservation
- No user data, migrations, Google integration configuration, or calendar functionality intentionally changed.
- Existing self-repair of the package tracker remains pinned to the **immutable v1.5.0-beta** tracker-runtime archives and their SHA256SUMS; this new release does not duplicate those ~1.6 GB external runtime bundles.
- The new beta.1 release contains checksum-verified Linux AMD64/ARM64 Calden updater bundles and, upon successful CI image publication, an isolated `ghcr.io/gigabytegrove/calden:1.5.0-beta.1` image.
- Do not install stable v1.4.12 over an existing 1.5.0 beta instance; use the in-app Beta-channel updater after the new release appears.

## Acceptance
GitHub workflow must pass Go tests and vet, frontend regressions, archive checksums, and integrated container build before publication. Existing containers and databases are not modified by release publication.
