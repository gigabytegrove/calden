# CalDen 0.1.0-alpha11.4

## Calendar

- Bill events now show a compact status marker directly on the calendar.
- **Allocated** bills show a distinct allocation marker.
- **Paid** bills show a checkmark.
- **Cleared** bills show a stronger cleared marker so they are visually distinct from merely paid bills.
- The normal bill status text remains available in the event metadata and Bill Activity panel.

This builds on alpha11.3's bill lifecycle and Google/all-day date rendering fixes.
