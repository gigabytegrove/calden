# Calden 1.5.0 — Production release

Calden 1.5.0 is the production promotion of the complete, security-qualified 1.5.0-beta.1 feature set. It is not a downgrade to 1.4.x.

## Included functionality
- Shared calendars, lists, categories, family care, recipes and meals, routines, rewards, and notifications.
- Credential-free local package tracking using the embedded Chromium/Node carrier recognition runtime, including supported self-repair.
- Google Calendar migration and duplicate repair; protected, in-place update and rollback processes.
- Existing persistent PostgreSQL data, credentials, and configuration remain compatible. No data wipe or migration rollback is part of this publication.

## Security baseline
- Go compiler/standard library **1.27.4**.
- PostgreSQL driver `github.com/jackc/pgx/v5` **5.13.0** (addresses the 2026 pgx advisories).
- Patched transitive Go dependencies carried forward from v1.5.0-beta.1.
- Multiarchitecture AMD64 and ARM64 Linux release binaries and GHCR image.

## Tracker recovery
- The production release includes checksum-verified AMD64 and ARM64 tracker-recovery runtime archives, copied byte-for-byte from the approved v1.5.0 Beta release.
- In-app tracker repair now points at **v1.5.0**; recovery no longer depends on a prerelease tag.
- The same immutable recovery assets are validated against the published Beta release SHA256SUMS before production publication.

## Updating
Install the v1.5.0 release via Calden Settings → Updates, on the Stable channel. Calden's updater stages a safety backup, validates SHA-256 and runtime versions, and installs the new binary. Preserve existing database mounts and `/data` volumes. Container operators should switch to `ghcr.io/gigabytegrove/calden:1.5.0` after their own backup/acceptance checks.
