# CalDen 0.1.0-alpha9.1

This is a one-time updater bridge for installations currently running CalDen 0.1.0-alpha9.

Alpha9's updater compared prerelease labels lexically, which means it incorrectly treated `alpha9` as newer than `alpha10`. As a result, Alpha10 was published correctly on GitHub but did not appear as an available update inside an Alpha9 installation.

This bridge contains the Alpha10 application code plus a corrected updater that compares numeric suffixes naturally.

Install **0.1.0-alpha9.1** once from the Updates page. After CalDen restarts, check for updates again and the current Alpha10-series release will appear normally.

No user data migration or rollback is required beyond the normal CalDen update process.
