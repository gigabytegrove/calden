# CalDen 0.1.0-alpha5

This release is focused on the CalDen web app. Android development is intentionally parked while the browser experience is brought to a complete, dependable state.

## Calendar workspace

- Real 1 Day, 7 Day, 14 Day, and 30 Day calendar layouts
- Sunday or Monday week starts are reflected in the actual calendar grid
- Click an empty time slot to create an event at that time
- Quick-add buttons on 14/30 day cells
- Current-time marker in 1/7 day views
- Optional automatic scrolling near the current time
- Overlapping timed events are laid out side by side instead of covering each other
- Events that cross midnight render correctly
- Calendar navigation reloads the appropriate event range
- Calendar, category, person, and text filtering
- Calendar visibility can be changed from the calendar strip or Settings

## Event presentation

- The calendar owns the event color
- Category remains independent metadata for filtering and organization
- Assigned people are shown with their real profile images when available, with initials as fallback
- Repeating events remain visually identified without overriding the calendar color
- Calendar and category names are shown as useful event metadata rather than competing visual systems

## Event editing and reminders

- New events can use a preferred default calendar
- Configurable default event length for this browser
- Multiple personal reminders per event
- Multiple household / Monita reminders per event
- Optional per-reminder Monita channel override
- Existing events load every saved reminder back into the editor
- Recurring event series and one-occurrence editing continue to use the same event editor

## Settings

Settings is now a full interface instead of a pair of generic cards.

- Household settings
  - Family calendar name
  - Time zone
  - Week start
  - Default calendar view
- Calendar & display settings
  - Preferred calendar for new events
  - Default event length
  - Current-time scrolling
  - Per-calendar visibility
- Your account
  - Profile image controls
  - Name, username, and account type

## Notifications

The Notifications page is now a working reminder schedule instead of an explanation screen.

- Shows upcoming scheduled reminders from calendar events
- Personal and household reminder totals
- Filter by personal or household reminders
- Shows scheduled delivery date/time, lead time, event, calendar, and assigned people
- Click a scheduled reminder to open its event

## Reliability

- Fixed the web startup regression caused by using a single-element selector as a collection
- Fixed the matching signed-in selector regression
- Browser validation now exercises first-run setup and the signed-in product in Chromium
- Browser validation covers calendar layouts, filters, multiple reminders, Notifications, People, Categories, Settings, and Activity
- Existing recurrence, iCalendar, backup/restore, and Docker Raw validation remain in the same end-to-end suite

## Android

Android development is deliberately deferred for this release. No Android build status is represented by this server/web release.
