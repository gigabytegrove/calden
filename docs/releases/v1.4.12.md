# Calden 1.4.12 — emergency security update

This release updates `github.com/jackc/pgx/v5` from 5.7.6 to 5.13.0, addressing the 2026 PostgreSQL driver security advisories (including CVE-2026-33815, CVE-2026-33816 and CVE-2026-41889) and newer reliability fixes. The Go build baseline is upgraded to 1.27.4 to incorporate the November 10, 2026 Go security fixes.

The changes preserve calendar data, database migrations, credentials, and user-facing behavior. The release pipeline must pass web and Go tests and publish checksum-verified Linux amd64 and arm64 binaries. Update existing installations only after the release artifacts have been verified.
