# Calden 1.4.1 — Shared chores and family devices

## What's new

- **Tasks & Chores:** Make chores repeat each day, week, every other week, month, or year. Assign one chore to several people, and each person can mark their own work as in progress or done.
- **Choose what to show:** The household administrator can hide or show **Bills** and **Agenda** in Settings without deleting anything.
- **See signed-in devices:** Household administrators can see which phones or devices belong to each family member. Each person can still manage their own connected devices.

## What you need to do

Update Calden from **Settings → Updates**. Existing chores, bills, payments, calendars, and appointments are kept.

**Android:** These server features require a compatible Android build. Do not treat Android source-code changes as an installable app until a tested APK has been published.

### For the person hosting Calden

The database update keeps existing chores and adds separate progress tracking for everyone assigned to a task. As with any server update, keep a backup.
