# CalDen 0.1.0-alpha3

CalDen 0.1.0-alpha3 is the first rolling build that uses the full application layout instead of the original prototype-style management screen.

## Calendar

- Real 1-day hourly timeline
- Real 7-day hourly timeline
- 14-day two-week grid
- 30-day rolling calendar grid
- Previous, next, and Today navigation
- Calendar visibility filters
- Calendar color remains the definitive event color
- Assigned people remain visible on events
- Events can be opened directly from calendar blocks
- Searchable agenda remains available as a secondary view
- All-day event editing is supported

## Full application interface

- Persistent desktop navigation
- Dedicated Calendar page
- Dedicated Agenda page
- Dedicated People administration
- Dedicated Calendars administration
- Dedicated Notifications page
- Dedicated Integrations page
- Dedicated Updates page
- Dedicated Settings page
- Responsive mobile navigation

The old Manage CalDen modal is no longer the primary administration interface.

## People and permissions

- Add family members
- Edit names and roles
- Reset passwords
- Activate or deactivate accounts
- Calendar visibility access
- Calendar editing access
- Edit calendar name, color, and description

## Settings

- Household name
- Time zone
- Week start preference
- Default calendar view
- Signed-in account information

## Monita

- Dedicated integration settings
- Test notification
- Household reminder delivery
- Delivery retry tracking remains server-side

## Managed updater

- Stable, RC, beta, alpha, and preview channels
- Release discovery and release notes
- Detailed update activity
- Download progress
- SHA-256 release verification
- PostgreSQL safety backup before installation
- Runtime verification before activation
- Persistent staged runtime
- Automatic restart into the new version
- Rollback metadata and rollback control
- Container restarts continue using the updater-managed runtime

## Reliability

- Fixed the add-person browser crash caused by using an expired event currentTarget
- Expanded browser CI signs in and adds a second user
- Browser CI verifies all four calendar layouts
- Browser CI saves household settings
- Docker Raw deployment remains part of automated smoke testing
