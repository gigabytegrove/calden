# CalDen v1.2.8

Web branding and authenticated-reload repair.

- Embed the existing official CalDen WebP logo into the login and sidebar HTML to bypass missing or incorrectly routed asset responses.
- Give transparent branding a contrasting background while preserving the supplied logo.
- Display the application shell immediately during authenticated session restoration instead of showing the login/startup splash on every reload.
- Preserve a visible startup error and retry control when synchronization fails.
- Keep the bundled SVG favicon and versioned web asset URLs.

This release does not replace or modify the Android application.
