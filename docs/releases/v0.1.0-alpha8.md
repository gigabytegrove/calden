# CalDen 0.1.0-alpha8

This release fixes destructive calendar cleanup and tightens Google Calendar export handling against a real Google export layout.

## Calendar deletion override

- Empty calendars can still be deleted normally.
- Calendars that contain events are no longer a dead end.
- CalDen shows a destructive confirmation dialog with the number of event series that will be removed.
- To proceed, the administrator must type the exact phrase `DELETE <calendar name>`.
- The server validates the confirmation as well as the browser, so the override cannot be triggered accidentally by the UI alone.
- Deleting the calendar uses the database's existing cascade rules to remove its events, recurring-event data, reminders, bill metadata, permissions, and import bindings.
- The browser clears deleted calendar visibility/default preferences and reloads events immediately afterward.

## Google Calendar export handling

A real Google Calendar ZIP exposed a Google quirk: the special Birthdays export can use the account email address as `X-WR-CALNAME` even though the exported filename correctly identifies the calendar as Birthdays.

- CalDen now recognizes that Google filename pattern and labels the special calendar as `Birthdays`.
- The primary account calendar still keeps its account/email calendar name.
- Normal named Google calendars continue to use their exported calendar name.
- When two existing CalDen calendars score equally well for a Google calendar, CalDen no longer picks one arbitrarily. The preview requires a manual destination instead.
- Previous auto-created Google duplicate calendars are not selected by default when there is no confident replacement match.
- This improves preview matching and prevents the special Birthdays feed from being mistaken for the primary account calendar.

## Validation

- Adds a real-browser test that creates a calendar, creates an event inside it, verifies normal deletion is blocked, completes the typed destructive confirmation, and verifies both the calendar and event are removed.
- Adds unit coverage for Google's special Birthdays filename behavior.
- Existing Google mapping, recurring event, iCalendar, backup/restore, and Docker deployment tests remain enabled.
