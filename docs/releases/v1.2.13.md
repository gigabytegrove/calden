# CalDen 1.2.13 — Coordinated widget and avatar correction

## Android
- Upcoming Bills widget uses a bill-status glyph (allocated ⌛, partial ◐, or general bill ▣) rather than repeating the due date in the icon slot.
- The due date is displayed once, alongside bill title and amount.
- Member photographs, when configured, always take priority over initials in event/agenda widgets.
- Photo downloads now accept the same 10 MiB limit as the CalDen web/server avatar uploader (previously capped at only 512 KB).
- Downloaded avatars are decoded at a bounded size and cached as transparent PNG thumbnails.
- Avatar cache keys include the image URL to avoid displaying stale photos.

## Web and server compatibility
- Existing avatar delivery already supports photos up to 10 MiB and needs no API change.
- Web client version aligned to 1.2.13; no calendar behavior changed.
- Official transparent CalDen branding from 1.2.12 remains unchanged.

Android must be built and signed locally before installation; publishing the web updater bundle does not build an APK.
