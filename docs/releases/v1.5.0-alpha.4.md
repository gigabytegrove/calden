# Calden 1.5.0-alpha.4 — Appearance, Meal Planning and Integrations

**Alpha-channel prerelease for the existing in-app updater.** Stable 1.4.8 remains unchanged.

## Personal appearance — fixed

A visible **Settings → Appearance & calendar** selector now offers Follow my device, Light, or Dark. Saving uses the existing authenticated per-user dashboard preferences record and preserves widget order and guardian-owned child layout. The dashboard customization selector stays synchronized with Settings; no separate theme state or browser-only preference is introduced. Follow my device honors operating-system dark-mode changes.

## Optional Meal Planning

Administrators now have **Settings → Optional Features → Enable Meal Planning**. The switch is on by default for backwards compatibility. Turning it off removes the Meal Planning entry and blocks direct access and *all meal-plan proxy API operations* for household users, including writes. This never deletes RecipeCove recipes or plans. Re-enabling restores access.

## Integrations cleanup

A **RecipeCove** card is now visible under **Settings → Integrations**, alongside clearly separated sections for **Calendar migration (Google Calendar)** and **Notification delivery (Monita)**. The RecipeCove card reports whether its server environment is configured and whether Meal Planning is enabled. It provides a configuration recheck and a shortcut to the feature switch without exposing any API key.

**Important limitation:** RecipeCove's scoped integration API remains a candidate requiring independent verification in the RecipeCove repository. "Configured" does *not* claim a successful API connection or working two-way meal synchronization. The current administrator setup still uses server environment settings `RECIPECOVE_URL` and `RECIPECOVE_SYNC_KEY`; no new unaudited token storage system is introduced here.

## Earlier alpha fixes preserved

Single icon and label per navigation route, responsive sidebar and notifications, and coordinated Light/Dark application shell from alpha.3.

## Validation and acceptance

The release job executes all Node/browser tests, Go unit tests, Linux AMD64 and ARM64 builds, packaging and SHA256 verification. Browser coverage includes appearance changes, disabled meal-route redirection, and a household toggle save. Local in-place update, RecipeCove compatibility, and visual acceptance still need testing. Back up your data before installing an alpha update.

Bundled for the updater: `calden-linux-amd64.tar.gz`, `calden-linux-arm64.tar.gz` and `SHA256SUMS`.
