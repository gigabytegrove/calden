# CalDen 1.0.3

Hotfix for web startup after the URL navigation and caching changes in 1.0.2.

- Separate genuine startup failures from errors raised after the application has loaded.
- Display the underlying startup error and an explicit Reload CalDen action rather than an undiagnosable generic banner.
- Preserve signed-in sessions when a nonauthentication startup operation fails, instead of clearing the token.
- Load the selected bill month when opening the bills permalink directly.
- Prevent repeated same-version automatic refresh loops after updating.
- Add authenticated browser boot regression coverage for calendar, bills and settings deep links.

Existing data, access control and Google Calendar duplicate behavior are unchanged.
