# CalDen 1.0.1

Single left click now opens a read-only details dialog for calendar events, bills, agenda items, notifications, and scheduled reminders. The details view shows event information, assigned people, notes, bill amounts, payment status, and payment history. Explicit Edit event and Manage payments actions preserve existing permissions and recurring-event scope behavior.

Bill management is reorganized into a clear overview, payment history, payment entry, allocations, and a separate zero-balance action. The dialog has aligned fields and responsive desktop/mobile styling.

No database migration or Google Calendar duplicate cleanup change is included. Install through CalDen Updates on Stable; the updater verifies release bundles and creates a safety backup before activating.
