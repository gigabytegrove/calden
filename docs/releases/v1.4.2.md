# Calden 1.4.2

## Appointment date integrity
- Event create/update endpoints now read back the timestamps that PostgreSQL persisted.
- Web and Android compare persisted timestamps with the requested dates before reporting a successful save.
- The web editor explicitly displays a review of both dates before saving and rejects invalid date ranges.
- Android event editor retains changes to the initial date, shows an explicit appointment review, and no longer mixes the device timezone with the household timezone across calendar and event details.
- Widget Quick Add also validates the authoritative stored dates before showing "Event created".
- New integration regression test creates a January 13, 2027 appointment and verifies it is never stored as October 13, 2026.

## Android notification sound controls
- Each category has a distinct small built-in Calden tone.
- Settings → Notification sounds offers Calden tone, phone default, selected tone, silent delivery, or disable alerts for the type.
- Every calendar offers an override of those notification-type settings.
- The same policy is used by FCM push, the live WebSocket, inbox polling, and the local reminder alarms.
- These choices are device-local and account-scoped. They do not delete in-app calendar entries.
- Android notification channel sound settings are immutable after creation; selecting a new option creates a new channel rather than trying to overwrite it.

## Data and rollout
- Migration 027 records the calendar identity in notifications. Existing calendar/event data remains unchanged.
- Update Calden server to 1.4.2 before installing the matching Android client.
- Back up your database before upgrading.
