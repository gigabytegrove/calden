# Calden 1.4.2 — Clearer appointment and notification dates

## What changed

- Before saving an appointment, Calden shows its full start and end dates so you can check the **month, day, and year**.
- Calden reads back the saved appointment's date and warns if it cannot confirm that the correct one was recorded.
- In **Notifications**, the date an alert was sent is labeled separately from the date of the appointment itself. Seeing “Notified Oct 13” next to a January appointment does **not** mean the appointment moved to October.
- Calden now keeps track of which calendar a notification belongs to, helping the Android app support calendar-by-calendar notification choices later.

## What you need to do

Update through **Settings → Updates**. Your existing appointments are not changed by this update.

**Android:** New notification sounds, including individual tones and the option to silence calendars, are being developed in the Android companion app. **They were not included in the server APK or released as an Android installable with 1.4.2.** Only install a verified Android build when one becomes available.

### For the person hosting Calden

This update adds a small database change for calendar notifications. It preserves the existing appointments and allows the server to identify each notification's calendar, even if an appointment is later cancelled. Keep a backup before updating.
