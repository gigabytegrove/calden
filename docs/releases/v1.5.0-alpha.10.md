# Calden 1.5.0-alpha.10 — Package Tracking UI Test

This prerelease makes carrier checking accessible in the Packages list: each active editable shipment displays **Check tracking now**, the last attempted carrier lookup, the next scheduled attempt, and carrier lookup errors. The page now distinguishes reloading saved packages from contacting public carrier sources.

A new package still triggers the existing background lookup on save. Active packages use the existing three-hour scheduler. This update does not guarantee that public carrier sites will return status data, and does not add any paid API requirement.

The Docker image includes the bundled Node/Chromium-based parcel scanner. In-app updater archives contain the Go runtime and web UI; they rely on a Docker installation that already contains the bundled scanner (or an equivalent existing runtime). For complete installation use `ghcr.io/gigabytegrove/calden:1.5.0-alpha.10`.

This is a testing prerelease, not an announcement of successful live scans.
