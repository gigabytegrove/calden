# Calden 1.3.2

This maintenance release builds on the deployed Calden 1.3.1 server and Android application.

- Correct the Android confirmation and request-change experience with visible response status, success feedback, and the ability to revise or withdraw responses.
- Add server support for withdrawing a confirmation and returning it to pending.
- Add version-numbered Android APK output under `app/build/outputs/versioned/` while retaining standard Gradle outputs.
- Set Android versionName to `1.3.2` and versionCode to `24`.

Android requires a new native APK build. The server release is independent of the Android APK. Verify build and device behavior before deployment.
