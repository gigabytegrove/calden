# Calden 1.5.0-alpha.2 — Unified Navigation & Appearance

This is an **alpha channel GitHub prerelease**, not a stable version. It improves the existing family-focused Calden web app without changing any module's API, database schema, or enabled-state policy.

## UI fixes

- The desktop sidebar now consistently renders a single 19px icon and one title for every route, including Meal Planning, School, Home Upkeep, and Pets.
- Normalized sidebar markup prevents duplicate `Tasks & Chores Chores` or other combined titles after household appearance settings are loaded.
- Customized household labels and approved custom icons remain supported. Standard Tasks/Chores visibility combinations display the appropriate singular or combined label.
- Navigation spacing, scrolling, avatar section, notification badge and long custom titles have stable alignment.
- Selecting Dark or following a dark operating-system appearance now styles the entire application workspace, top bar, headers, calendars, forms, notifications and dialogs, rather than only family module cards.
- Light mode retains Calden's dark branded sidebar but keeps the main workspace, cards and form controls light; household accent color presets are kept separate from the user’s light/dark choice.
- Notification action buttons no longer wrap arbitrarily in desktop width; mobile controls reflow.
- Accessibility: accessible icon markup, reduced-motion navigation behavior and focus outlines.

## Quality gates

Publisher runs the entire Node/jsdom test suite, Go unit tests and cross-platform Linux runtime builds before publishing. Includes new DOM regression tests verifying idempotent nav decoration, all routes having icons, notification badge retention and the Tasks/Chores customization boundary.

Bundled assets: `calden-linux-amd64.tar.gz`, `calden-linux-arm64.tar.gz`, and `SHA256SUMS`. Compatible with the **existing** Calden in-app updater on the **Alpha** channel. No new background service is required.

## Upgrading

Back up existing Calden data, then choose Settings → Updates → Alpha and check for `1.5.0-alpha.2`. The test scope for this release is appearance and browser navigation. Remaining alpha family features still require local acceptance and Android parity. Stable `1.4.8` is unchanged.
