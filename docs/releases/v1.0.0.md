# CalDen 1.0.0

The first stable CalDen release marks the existing household calendar and Bill Pay application as ready for ongoing use and iterative improvements. This version includes all changes through the October 7 web stability work.

## Included

- Day, week, two-week, and 30-day calendar views, recurring events and occurrence editing
- Multi-user household management, calendar permissions, assignments, and notifications
- Bill Pay allocations, split and partial payments, zero-balance occurrences, actual payment dates, clearing dates, and payment history
- Calendar migration and import/export tools
- Integrated backup/restore and in-place updates with safety backups, integrity checks, activity tracking, and rollback support
- Date-only handling, safer payment input validation, resilient browser preferences, and serialized updater polling

## Updating from alpha

Select the Stable channel in Updates if necessary, then check for version 1.0.0. The updater requires the published v1.0.0 GitHub Release with Linux amd64/arm64 runtime bundles and SHA256SUMS. Data is retained; the updater takes a database safety backup before installation. If installing from Docker rather than the in-app updater, rebuild the service against this version without deleting volumes.

Calendar duplicate cleanup is intentionally unchanged in 1.0.0.
