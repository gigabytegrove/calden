# Calden 1.4.7 — Easier-to-use payment buttons

This update makes Calden's payment history easier to read and use. It fixes a display problem where several payment actions appeared to run together as ordinary text.

## What's improved?

- **Easy-to-see payment buttons:** Each payment now has its own clearly outlined **Mark cleared**, **Edit**, and **Delete** controls. The Delete button is red, so it is easier to recognize before removing anything.
- **More comfortable spacing:** The payment amount, person who paid, payment date, clearing status, and available actions have their own space. Actions wrap neatly on smaller screens instead of colliding.
- **A clearer Backups page:** **Download** and **Delete** use the same button style as Calden's other management screens, with a red Delete action.
- **Better keyboard access:** These actions have visible keyboard focus, and payment buttons have clearer descriptions for screen readers.

## Does this change any payments or family information?

**No.** All recorded payments, payment dates, cleared dates, bills, accounts, and saved backups remain exactly as they were. Button behavior is unchanged; only how the controls look and fit has improved.

## How to install

Open **Settings → Updates** in Calden and install **1.4.7**. Refresh the browser afterward if the older styling is still visible. Calden does not need a database migration for this update.

The Android app is separate from the server/web release; **this does not publish a new Android APK**.

## Verification

The automated browser tests check that payment actions remain visible and separated on desktop, tablet, and narrow phone-size layouts. Existing payment, backup/restore, and server tests are also run before the release is published.
