# Calden v1.5.0-alpha.11 — Package Tracking Usability

- **Two-field package entry:** Enter a package name and tracking number. Carrier is detected by Calden and checked through the existing keyless local tracking engine. Carrier, status, estimated date, notes and household sharing are under optional details.
- **Delete packages permanently:** An owner can remove a package from its row or editor after confirmation. Its checkpoints are deleted by database foreign-key cascade; other household members cannot delete it.
- **Re-add old test numbers:** Adding a previously archived tracking number removes the owner's archived duplicate and creates a fresh shipment. Active duplicates are still rejected.
- **Keep carrier verification:** Editing a name or notes without changing the status no longer marks a carrier-verified status as manually set.
- **Guided email discovery:** Gmail is the default, with server hostname auto-selected from a Gmail address and secure inbox checks approximately every 15 minutes. Users enter their email and a dedicated Gmail app password; no Calden server-side piping or API account is needed. Advanced administrator-approved IMAP hosts and gateway forwarding remain optional.
- **Live UI updates:** The Packages screen refreshes its list every 60 seconds while open, picking up background carrier and mailbox scans.
- **Tests:** Owner-only permanent deletion and re-add integration test; safe Gmail host resolution; UI contracts.

**Limits:** This release does not implement Google or Microsoft OAuth. Gmail app passwords require Google 2-Step Verification and may not be available to every account. Outlook/Microsoft 365 mailboxes need OAuth and cannot connect using the existing IMAP password flow. Carrier websites may block automated lookups; no status or scan is fabricated. The *full Docker image* includes the Node/Chromium scraper; the in-app binary updater contains the Go server and UI, not bundled Node/Chromium dependencies.
