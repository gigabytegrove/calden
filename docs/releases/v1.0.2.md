# CalDen 1.0.2

- Page navigation uses real paths for calendar, bills, agenda, household management, settings and administration.
- Calendar dates and bill months are URL-addressable. Event and bill occurrences get unique shareable URLs, and details include Copy link.
- Browser Back/Forward and opening a deep link after sign-in restore the requested view with existing permissions enforced.
- No-store cache headers apply to all UI resources, including static assets, and a running-version check reloads stale clients after updates without requiring Ctrl+F5.
- No database migrations or Google Calendar duplicate changes.
