# Calden 1.4.6 — Tasks and Chores icon fix

This small update restores the navigation icon for **Tasks**, **Chores**, and **Tasks & Chores**.

## What changed?

- The task-list icon no longer disappears when you enable or disable Tasks or Chores in **Settings → Optional Features**.
- The menu text still changes to match the features your household has enabled, but it no longer replaces the existing icon.
- Automated browser checks now verify the icon remains in place when Tasks and Chores are switched on and off.

## What do I need to do?

Open **Settings → Updates** and install **1.4.6**, then refresh the page if needed.

This update does **not** change appointments, household settings, bills, tasks, chores, their assignments, or completion history. No database change is required.

## About the Android app

This update is for Calden's server and web interface. It does not include a new Android APK.
