# Calden 1.4.5 — Optional Features

You can now choose the parts of Calden your family wants to use, all from one place.

## What changed?

Open **Settings → Optional Features**. You'll find four switches:

- **Enable Bills:** Show or hide Bill Pay.
- **Enable Agenda:** Show or hide the upcoming-events list.
- **Enable Tasks:** Allow assigned household tasks.
- **Enable Chores:** Allow chores, including repeating chores.

Each switch saves automatically for the whole household. Turning one feature off does **not** turn the others off.

## What happens to existing information?

Nothing is deleted when you turn a feature off. Bills, appointments, tasks, chores, assignments, and completion history stay saved. If you turn the feature on again, its existing information becomes available again.

Previously, Calden treated Tasks and Chores as one feature. They are now distinct types that can be enabled separately. Existing entries remain **Chores** so their information and history stay intact. New items can be marked **Task** or **Chore**.

Only a household administrator can change Optional Features. Other family members use the enabled features normally.

## How to update

In Calden, open **Settings → Updates** and install **1.4.5**. Reload the page after updating.

The update adds a small database change to identify tasks separately from chores. Calden applies it automatically; no manual database commands are needed. Back up your Calden data before updating, as usual.

**Android:** The Android APK is developed and released separately. This is a server/web release; it does not publish a new Android installer.
