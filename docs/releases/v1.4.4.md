# Calden 1.4.4 — A clearer experience for families

This update makes Calden more consistent and easier to understand. It does **not** remove your calendars, appointments, bills, chores, or reminders.

## What changed

- **One name everywhere:** The app, sign-in screen, widgets, menus, and help consistently say **Calden** instead of mixing different capitalizations.
- **Easier first-time setup:** Calden now explains the first account and household setup in everyday language.
- **Clearer messages:** When something goes wrong, Calden shows useful next steps instead of requiring you to understand server logs.
- **Backups and updates make more sense:** The screens explain what happens before an update or restore without relying on technical terms.
- **More useful instructions:** The README and release notes now start with what families need to know. Hosting and development details remain available separately.

## What you need to do

Open **Settings → Updates** in Calden and install version **1.4.4** when it appears. Your family's existing information stays in place. As with any update, keeping a current backup is recommended.

### For the person hosting Calden

The new backup format shows the consistent Calden name. Backups made by older versions using the previous capitalization are still supported for restore. No new accounts or settings are needed.

**Android:** The matching branding improvements are on the Android development branch; they are **not** part of this server update, and an Android APK should not be installed until its separate build has passed verification.
