# Calden 1.4.4

**A clearer Calden for the whole family.**

This update makes Calden easier to recognize and understand, especially when someone is setting it up or using it for the first time.

## What's changed

- **One consistent name:** The website, sign-in and setup screens, loading messages, and help text now call the app **Calden**. We corrected places where it was written “CalDen.”
- **A simple getting-started guide:** The new [Family Quick Start](https://github.com/gigabytegrove/calden/blob/main/docs/FAMILY_QUICK_START.md) walks through adding family members, choosing calendars, scheduling appointments, and deciding who can see or edit each calendar.
- **Clearer advice about reminders:** The guide explains why an appointment date may differ from the date a notification was sent.
- **More helpful project information:** The README now points families to the quick-start guide and shows the correct current server version.

## Do I need to do anything?

**Just install the update from Calden's built-in updater.** Reload the webpage if it was already open.

Your existing appointments, calendars, bills, reminders, user accounts, and preferences are not changed. There is no new database migration in this release.

## Which version should I install?

- **Calden server/web:** 1.4.4 — available through the server's built-in updater.
- **Calden Android:** This update does **not** include a new Android APK. Android builds are released separately, only after a successful build and verification.

For help after installation, open the [Family Quick Start](https://github.com/gigabytegrove/calden/blob/main/docs/FAMILY_QUICK_START.md).

## For administrators

Both Linux runtime packages and the container image are built by the official release workflows. Back up your Calden data before updating. This update is a branding and documentation improvement; no settings or service changes are required.
