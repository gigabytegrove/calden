# Calden 1.3.3

## Android fixes
- Compact top app bar with status-bar-safe insets and more room for calendar content.
- Month widget now clears its separate upcoming-events container when refreshed, preventing accumulated duplicate items.
- Appointments no longer inherit a bill-style Due label in the agenda.
- Date-only bills show Due date wording instead of All-day event in the agenda and details.
- Event assignees use selectable family photo/initial cards rather than name checkboxes.
- Event editor and detail modal use the household's configured time zone for date/time display and editing.
- Nearby agenda event times display relative time when appropriate.
- Android Settings includes a personal appointment confirmation preference.

## Server changes
- Appointment confirmation requests exclude the event creator and honor each assignee's confirmation preference.
- An authenticated member can update their own confirmation preference; the server checks eligibility when responding.
- New database migration 018 adds the confirmation preference.

## Validation
- Android versionName 1.3.3; versionCode 25. Android APK is built separately from the server release.
- Device/layout regression and end-to-end time zone testing are still required before this release can be considered fully validated.
