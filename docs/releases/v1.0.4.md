# CalDen 1.0.4

- Fix two fatal navigation/settings JavaScript selectors that used querySelector rather than querySelectorAll before `.forEach()`, preventing startup after v1.0.2.
- Forward bounded, authenticated browser JavaScript errors to server stderr so they appear in container logs and Dokploy logging, where configured to collect container output.
- Keep stable URLs, event/bill permalinks, and cache refresh fixes. No schema or duplicate changes.

For broken installed 1.0.2/1.0.3 instances, use the documented CLI selector patch to restore the interface, or install the verified runtime bundle manually using the CalDen runtime directory.
