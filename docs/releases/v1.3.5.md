# Calden 1.3.5

## Household and personal week start
- Administrators can change the household week start at any time using Household settings on the web or Android.
- Every family member can choose Sunday, Monday, or inherit the household default.
- Your individual preference is stored on the Calden server and follows your signed-in account across web and Android.
- Android month layouts and home-screen calendars follow the effective week start, including correct week headings and date alignment.

## Planner role
- New **Planner** role for managing calendars, categories, shared events, calendar access and bill-pay calendars.
- Planner cannot administer user accounts, household settings, system upgrades, backups, or integrations.
- Existing family members keep their current roles and calendar data.
- Server-side permissions are enforced on each relevant API endpoint, not only hidden in the interface.

## Android home-screen widgets
- Calendar widget dates are selectable directly from the home screen.
- The selected day's event titles appear inside the widget without launching the full app.
- Tap **+ Add** on any widget to open a new event already set to the chosen date.
- The weekday headers distinguish **Tuesday (T)** from **Thursday (Th)**.
- Existing agenda, bill and calendar widget layouts remain available.

## Android event editor
- Moving an event's start date or time automatically shifts the end by the same duration.
- Changing an end date/time to an invalid value clearly displays the reason Save is disabled.
- Validation messages also explain missing titles, calendars, invalid bill amounts and recurrence requirements.

## Deployment
Server images: `ghcr.io/gigabytegrove/calden:1.3.5` or `latest`. The in-app updater uses the matching GitHub release; data schema migration 019 runs automatically.
Android 1.3.5 uses the same server API; install the versioned APK when it has been successfully built.
