# Calden v1.5.0 Beta — Approved Feature Baseline

**Promotion:** The complete feature implementation and UI from [v1.5.0-alpha.18](https://github.com/gigabytegrove/calden/releases/tag/v1.5.0-alpha.18) is approved and locked as **v1.5.0 beta**.

**Source of truth:** `alpha/v1.5.0-alpha.18` commit `b29edf4381761ffbb4d83a4d719253eb5b8ed4fb`. The beta differs only in release/version identity, explicit updater compatibility tests, release documentation, and the isolated beta publisher. The publisher checks the locked source delta and refuses unrelated implementation or UI changes.

## Included, unchanged from the approved baseline

- Family calendar, core household workflows, roles and permissions.
- Meals, Packages, shipping-email discovery and shipment-history UX, and existing calendar overlays.
- Built-in carrier scraper using the single-container Node/Chromium runtime, with no mandatory external API subscription.
- Self-repair on legacy Docker images, runtime verification, retry diagnostics, and managed tracking installation within the existing writable data volume.
- Tracking readiness persisted across in-app binary updates and container restarts, protecting a verified runtime from unnecessary "preparing tracking" states.
- Provenance-correct history: real carrier scan events distinguished from status-only provider updates.
- Established UI layout, styles, saved data paths, migration history and supported update/rollback behavior.

## Beta distribution and verification

- Tag: `v1.5.0-beta` (prerelease, not a stable/GA declaration).
- Image: `ghcr.io/gigabytegrove/calden:1.5.0-beta`, AMD64 and ARM64.
- Installable application archives: `calden-linux-amd64.tar.gz`, `calden-linux-arm64.tar.gz`.
- Local tracker-recovery archives: `calden-tracker-linux-amd64.tar.gz`, `calden-tracker-linux-arm64.tar.gz`.
- SHA-256 inventory: `SHA256SUMS`.
- Publish only after the release workflow passes Go and real PostgreSQL checks, web tests, native ARM64 and AMD64 tracker checks, archive safety and checksum checks, and the multi-platform Docker build.

The in-app updater must continue to offer the beta as a newer installable version to alpha users, without replacing the Docker image, changing its services, or losing existing household data.

## Acceptance limits

The beta is an approved feature baseline, not a claim that every carrier provider or an arbitrary existing NAS/host environment has been tested. Install/upgrade/rollback and real-provider tracking on the owner's live host still require independent acceptance evidence. Preserve this baseline in future patches unless a concrete tested defect requires a forward-only fix.
