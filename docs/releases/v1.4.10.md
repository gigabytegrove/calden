# Calden 1.4.10 — Package Tracking

Optional native shipment tracking with a new Packages workspace and calendar projection. The feature is **off by default** and appears in Settings → Optional Features.

## Included

- Add and manage Amazon Logistics, USPS, UPS, FedEx and other shipments; retain package names, tracking IDs, delivery dates, current status, notes and checkpoint history.
- Show deliveries directly on existing calendars without creating or duplicating regular calendar events. Expected dates move when edited.
- Private owner scope by default, with explicit household sharing and owner-controlled editing and archival.
- Import raw shipping email messages by pasting source or uploading `.eml`, extracting common carrier IDs. Duplicate imports are safely skipped.
- Optional inbound email forwarding endpoint authenticated by a high-entropy, individually revocable secret. Raw tokens are displayed once, and only SHA-256 digests are stored.
- Carrier links open official tracking pages, while status descriptions make it clear when a status is manual rather than carrier-verified.
- UI styling, API unit tests, input-validation checks, build verification, and documentation.

## Compatibility

Database migrations 041 and 042 run automatically when the upgraded server starts. Existing calendar records and package-free households remain unchanged. Feature toggling never deletes saved packages.

## Known limitations

This release does not authenticate to consumer Amazon, USPS Informed Delivery, UPS My Choice or FedEx Delivery Manager accounts, does not poll carrier APIs, and does not connect directly to IMAP/OAuth mailboxes. Automatic email receipt requires configuring a trusted mail gateway; manual import needs no external credentials.

See [Package Tracking documentation](../PACKAGE_TRACKING.md) for endpoints, forwarding and current limitations.
