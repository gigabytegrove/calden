# CalDen 0.1.0-alpha2

This rolling alpha moves CalDen from the initial foundation into the full product interface.

## Included

- Real application navigation instead of a single management modal
- 1-day, 7-day, 14-day, and 30-day calendar views
- Dedicated People, Calendars, Notifications, Integrations, Updates, and Settings areas
- Editable household settings and default calendar preferences
- User editing, role management, password reset, and account deactivation support
- Calendar access management
- Managed in-app updater with release channels, checksums, safety backups, staged runtime activation, progress reporting, and rollback metadata
- First-run and browser reliability fixes
- Official CalDen branding

This remains an alpha release while the Android and desktop interfaces continue moving toward feature parity.
