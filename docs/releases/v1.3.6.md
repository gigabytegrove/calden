# Calden 1.3.6

## Notification reliability and recurring events
- Fixed missing `notifications.occurrence_start` schema field through additive migration 020.
- Individual recurring-occurrence changes, cancellations and restorations now create participant notifications.
- Only confirmation records for the modified recurrence occurrence are invalidated.
- Authenticated notification inbox read/unread/dismissal API remains authoritative for web and Android.

## Monita integration
- Added scoped Monita service-account tokens (`SA.`) for channel discovery and message publishing.
- New web settings channel picker backed by Monita's `/service/channels` endpoint; a service token needs `channel:read` and `message:write` scopes.
- Monita integration tokens are encrypted at rest using Calden's existing persistent signing secret (AES-GCM).
- Legacy application tokens remain supported and are converted to encrypted storage when resaved.
- Back up the Calden data volume as well as the database: its existing signing secret is required to decrypt integration tokens.

## Android client coordination
Use Calden Android 1.3.6 for the improved home-screen widget, quick add and native notification inbox.

## Delivery and scope
CI includes Go build/tests, browser product smoke, recurrence and import tests, backup/restore and Docker Raw deployment.
Server containers: `ghcr.io/gigabytegrove/calden:1.3.6`. Release binaries target amd64 and arm64.

This release does **not** claim guaranteed instant push when Android background execution is restricted, full conflict detection, or a complete account-pairing wizard for Monita. Those remain separate work.
