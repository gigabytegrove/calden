# Calden 1.4.8

This update fixes the people selector when adding or editing tasks and chores.

- Keeps each checkbox, profile picture and name together inside its own selection card.
- Prevents names and profile pictures from spilling outside the card.
- Keeps selection highlighting and improves the layout on smaller screens.

No task or chore information needs to be recreated. Update Calden through Settings to receive the correction.
