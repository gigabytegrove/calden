# CalDen 1.3.0 — direct notification integration

CalDen 1.3.0 introduces the first direct server-to-client notification transport and expanded appointment notifications.

## Included in source
- Authenticated per-account WebSocket notification stream with browser and Android clients.
- Database-backed inbox and REST fallback, plus live browser inbox refresh.
- Assignment, confirmation request, schedule change and cancellation notifications.
- Android foreground WebSocket service with reconnection, native notifications, confirmation and request-change shortcuts.
- Session expiration enforcement and TLS-terminating reverse-proxy origin handling.

## Release qualifications
- No Firebase/FCM dependency.
- Android service reliability depends on operating-system background execution rules; 15-minute REST polling remains recovery fallback.
- Native Android APK is built separately from the server release and must be signed and verified.
- Source build and integration checks are required before deployment. The release version alone does not certify device compatibility.
