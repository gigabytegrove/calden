# Calden 1.5.0-alpha.3 — Consistent Light/Dark UI

This alpha supersedes 1.5.0-alpha.2 for UI testing. It preserves the same navigation, icon, duplicate-label, and notification layout fixes. It additionally ensures that the sidebar follows the selected appearance rather than remaining dark when the rest of the application is light.

- **Light:** light sidebar, top bar, cards, inputs, notifications and account controls, with accessible blue selection accents.
- **Dark:** dark sidebar and full dark workspace, including notifications, dialogs, settings, forms and calendar views.
- All approved household icon/name customizations remain supported; one icon and one title per route.
- No database migrations or API changes beyond the existing family-platform alpha.

Published as a normal updater-compatible GitHub alpha prerelease with Linux AMD64/ARM64 runtime archives and `SHA256SUMS`. Use Calden's built-in **Settings → Updates → Alpha** channel to install. Stable 1.4.8 remains unchanged.

The source is tested by the full Go and Node suites with added DOM navigation/theme regression coverage. Runtime browser appearance acceptance remains a user test.
