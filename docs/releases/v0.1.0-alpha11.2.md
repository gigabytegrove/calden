# CalDen 0.1.0-alpha11.2

This hotfix addresses the case where the Alpha11.1 calendar fix was installed but the browser could continue running an older cached `app.js`, making the duplicate-looking all-day event bug appear unchanged.

## What the Colquitt EMC case actually is

The Google export supplied for debugging contains this recurring bill event:

```text
DTSTART;VALUE=DATE:20250206
DTEND;VALUE=DATE:20250207
RRULE:FREQ=MONTHLY;BYMONTHDAY=6
SUMMARY:Colquitt EMC - House
```

That is one all-day event on the **6th**. The 7th is the exclusive iCalendar `DTEND` boundary.

Older CalDen browser code used an inclusive overlap check and rendered that single stored occurrence on both the 6th and 7th.

Alpha11.1 corrected the overlap logic. Alpha11.2 makes sure that corrected JavaScript cannot be hidden by a stale browser cache after an in-place update.

## Web update cache fix

CalDen now sends `Cache-Control: no-store` for HTML, JavaScript, and CSS application assets.

The main stylesheet and JavaScript bundle also use a release-specific query string in `index.html`, so the browser requests the new asset URL immediately after an update.

This avoids the situation where:

1. the server is updated,
2. the database and backend are current,
3. the browser still executes the previous `app.js`,
4. a UI bug appears to be unfixed.

## Existing all-day fix retained

Calendar event ranges remain half-open:

```text
[start, end)
```

A one-day all-day event ending at midnight on the following date is rendered only on its start date.

Server event-range queries and recurring occurrence rendering use the same exclusive-end behavior.

## Validation

CI now verifies:

- one-day all-day events render exactly once
- the server excludes events whose end is exactly the start of the queried day
- the web app links release-specific JavaScript and CSS asset URLs
- HTML, JavaScript, and CSS responses include no-store caching headers
- the existing Bill Pay, Google duplicate repair, recurrence, notification, backup/restore, and Docker deployment paths still pass
