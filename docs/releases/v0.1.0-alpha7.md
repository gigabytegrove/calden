# CalDen 0.1.0-alpha7

This release tightens two areas that need to behave like a real household product: bills and calendar migration.

## Bill Pay calendars

- Adds a first-class Bill Pay calendar type.
- Bill events can store an amount due, mark a variable amount as estimated, and assign one person as the payer.
- Bill amount and payer appear directly in calendar and agenda event presentation.
- Adds a Bill Pay workspace for every user who can see at least one Bill Pay calendar.
- Monthly overview shows expected total, known amounts, estimated amounts, bills due, responsibility by person, and totals by bill calendar.
- Existing CalDen calendar permissions determine who can see the Bill Pay overview and its underlying bills.
- Existing Bills starter calendars are migrated automatically to the Bill Pay type.

CalDen still does not track accounts, balances, income, transactions, or bank connections. This is intentionally a lightweight due-date and household-cost view, not a budgeting product.

## Google Calendar migration

- Replaces the previous one-click import with a preview-and-map workflow.
- Nothing is created until every exported Google calendar is reviewed.
- CalDen suggests existing calendar matches using normalized names instead of only exact text matches.
- Each Google calendar can be mapped to an existing CalDen calendar, explicitly created as a new calendar, or skipped.
- Re-imports continue to update matching event UIDs instead of duplicating events.
- When a Google calendar was previously imported into an auto-created duplicate, remapping it can safely remove the old duplicate after the events are imported into the chosen calendar.
- Cleanup is deliberately conservative: CalDen keeps an old calendar when it contains manually-created events or another active Google mapping and reports why it was retained.

## Validation

- Adds Bill Pay coverage to the real-browser product flow.
- Adds calendar-type checks to first-run CI.
- Adds Google calendar-name matching tests.
- Existing recurrence, iCalendar, Google migration, backup/restore, and Docker deployment tests remain in the validation suite.
