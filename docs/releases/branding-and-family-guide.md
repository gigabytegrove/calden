# Calden branding and family documentation

This change is about clarity, not new calendar features.

- The name appears as **Calden** throughout the main website, its setup screens, loading messages, and README.
- A new [family quick-start guide](../FAMILY_QUICK_START.md) explains creating calendars, scheduling events, setting who can see them, and understanding notifications.
- The guide describes the difference between an appointment's date and the date an alert was sent.
- Existing API addresses, internal identifiers, calendar data, and Android package names are unchanged.
- Android development continues separately; the next APK must pass compilation and testing before publication.

**No installation steps or data migration are required for these wording changes.**
