# Calden 1.3.8 — Tasks & Chores and live synchronization

## Tasks & Chores
- Separate household chore records: title, notes, due date, assignment, status and completion details.
- **Admin-only** household enable/disable switch, disabled by default; disabling preserves stored chores.
- Administrators and Planners assign, update or delete tasks. Assigned members update their progress.
- Overdue, pending, in-progress, completed and assigned-to-me views on web and Android.
- Additive PostgreSQL migration 021 for chores.

## Cross-device data updates
- Additive PostgreSQL migration 022 tracks durable data revisions on calendar, event, bill, and chore changes.
- The authenticated live notification stream sends a cache invalidation marker when data changes.
- Android refreshes foreground calendar/chores and schedules widget refresh; reconnect/resume performs catch-up.
- Background delivery remains subject to Android's OS power-management restrictions.

## Android 1.3.8 companion
- A distinct 30-day calendar widget with no upcoming event list, preserving the original widget.
- Event-editor Saving state; server-confirmed Event created/updated message and visible save errors.
- Native Tasks & Chores section and admin enable switch.
